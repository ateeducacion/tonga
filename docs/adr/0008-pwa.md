# 0008: PWA con service worker propio

Estado: aceptada (2026-10-02)

## Contexto

Tonga es estática, educativa y se usa en centros con mala conectividad. Tiene unas 3.400 imágenes en la biblioteca, que no se pueden precachear.

## Decisión

- `manifest.webmanifest` con iconos de 192 y 512 px, uno de ellos *maskable*, para poder instalarla.
- Service worker propio (`src/sw.js`, unas 70 líneas). Un plugin de Vite inyecta la lista de precache y la versión, que es un hash del contenido.
  - **App shell**: se precachea por versión, y las versiones antiguas se borran al activar la nueva.
  - **`catalog.json` y navegación**: red primero, con la caché como respaldo sin conexión.
  - **`repositorios/`**: se cachean bajo demanda, con un máximo de 300 entradas (FIFO).
  - **Actualizaciones**: una versión nueva espera. Un aviso ofrece «Actualizar», que primero escribe el autoguardado y después activa la versión y recarga. Nunca hay una recarga silenciosa, ni queda una versión vieja atrapada: cada build cambia el nombre de la caché.

## Alternativas

- **vite-plugin-pwa / Workbox** (MIT): muy completos, pero las tres estrategias de Tonga caben en unas 70 líneas legibles.

## Consecuencias

- El E2E `pwa.spec.ts` comprueba el manifest y la carga sin conexión (Chromium y Firefox).
- La biblioteca solo funciona sin conexión para las imágenes ya usadas.
